# Hospital Smart Service Operations Optimizer

## Overview

The Hospital Smart Service Operations Optimizer is a Java-based project developed for the DCIT 204/308 Data Structures and Algorithms I & II Semester Project.

The system is designed to improve hospital service operations by managing patient service requests, prioritizing emergency cases, assigning available resources, finding optimal routes between hospital departments and analyzing algorithm performance using custom-built data structures and algorithms.

---

## Features

- Hospital service request management
- Emergency case prioritization
- Resource allocation
- Patient and service record search
- Route optimization
- Database integration
- Performance analysis
- Algorithm comparison
